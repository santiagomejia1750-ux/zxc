# Proyecto académico — Conceptos

Sitio web académico desarrollado con HTML, CSS y recursos locales generados con Quarto.

## Ver el proyecto

Cuando publiques este repositorio con GitHub Pages, el sitio estará disponible en:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

Reemplaza `TU-USUARIO` y `NOMBRE-DEL-REPOSITORIO` por los valores de tu cuenta y repositorio.

## Publicar con GitHub Pages

1. Crea un repositorio **público** en GitHub.
2. Sube el contenido de esta carpeta al nivel principal del repositorio. El archivo `index.html` debe quedar en la raíz, no dentro de otra carpeta.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`; pulsa **Save**.
6. Espera a que termine la publicación. La URL aparecerá en la sección **Settings → Pages**.

## Archivos principales

- `index.html`: página web lista para publicarse.
- `styles.css`: estilos visuales del proyecto.
- `index_files/`: bibliotecas y recursos locales usados por la página.
- `index.qmd`: fuente editable de Quarto.
- `.github/workflows/`: flujos de trabajo incluidos en el proyecto original.

## Actualizar el sitio

Edita los archivos necesarios y vuelve a subir los cambios al repositorio. GitHub Pages publicará la nueva versión cuando termine el proceso de despliegue.
